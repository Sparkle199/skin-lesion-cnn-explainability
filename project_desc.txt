Project Title – Deep learning for multi-class skin cancer detection using CNNs and explainable AI: A performance and interpretability analysis. 
Project Aim - The aim of this project is to design and test different deep learning classification algorithms that utilize dermoscopic images for the multi-classification of skin cancers, particularly in terms of model choice, data pre-processing, optimization of training, performance analysis, and post hoc explanation techniques. The area of skin cancer detection becomes the practical setting in which the AI-based classifier is tested and evaluated using various CNN models.
Project Objectives - 
1. Analysis:
Perform a structured analysis of the literature on AI image classification technologies, particularly on the applications of CNN-based multi-class classifiers, data processing methods suitable for dealing with imbalances in dataset class numbers, and explainable AI (XAI) approaches (Grad-CAM, SHAP, and LIME).
2. Design:
Design an experiment to compare the effectiveness of multi-class CNN image classification through a series of tests carried out using three different CNN models which are ResNet-50, EfficientNetB4, and VGG-16 including the application of transfer learning and class balancing for addressing the imbalanced nature of the HAM10000 dataset. The Diverse Dermatology Images (DDI) dataset will be incorporated as a second, binary malignant/benign classification task, run alongside the primary seven-class task, to reduce the skin-tone homogeneity of HAM10000 and improve representation of darker skin tones in at least part of the experiment.
3. Development:
Implement and train all three CNN-based classifiers in two configurations: (i) the primary seven-class classifier, trained and fine-tuned on HAM10000 alone, using hyper-parameter optimisation to maximise multi-class classification performance across all seven image categories; and (ii) a secondary binary malignant/benign classifier, trained on a combined corpus of HAM10000 (relabelled to malignant/benign using its existing seven-class diagnosis) and the full DDI dataset (which already provides a malignant/benign label for every image), to make use of DDI's full 656-image sample without forcing its 78 distinct diagnoses into HAM10000's seven-class taxonomy.
4. Evaluation:
Perform an evaluation and comparison of the classification results from each of the models based on multiple metrics, namely accuracy, precision, recall, F1 score, ROC-AUC, and Cohen’s kappa, and evaluate the interpretability of the decision-making process by using Grad-CAM and SHAP as post hoc methods for explaining predictions.
5. Trade-off Analysis:
Conduct a critical analysis of the trade-off between classification accuracy and interpretability in the three models under consideration, determining the optimal CNN model in terms of balancing both aspects in the multi-class classification problem. 
Project Artefact type – Experiment
Brief description of your project (no more than 500 words), this should try and address the lifecycle of a project e.g. analysis (research), design, development, evaluation/testing, what will you do in each of these areas:
This project addresses the image classification problem with multiple classes using the technique of deep learning, namely Convolutional Neural Networks (CNNs). At its core, the AI problem is to train and compare the performance of various CNN models in terms of the ability to classify image data into multiple classes while looking into whether the decision-making process can be explained through post-hoc Explainable AI (XAI) methods. As the use case of the proposed method for image classification, the issue of skin cancer diagnosis will be considered, given that it presents a significant challenge in terms of the image processing required. Nevertheless, the objective of the project is not to develop an actual diagnosis system but only to test the performance of different CNN models and their explainability.
Analysis (Research):
A systematic review of recent literature shall be conducted, targeting CNN based multi-class image classification approaches, approaches to transfer learning, data pre-processing for imbalanced data sets, and post-hoc XAI techniques like Grad-CAM, SHAP, and LIME. The choice of experimental data set would include the HAM10000 database, which contains 10,015 images across seven classes for dermatological diagnosis. The justification for the selection of this data set will be its widespread application as a standard test data set for image classification experiments. The dataset release also includes lesion segmentation masks for all 10,015 images and the official ISIC2018 Task 3 held-out test set of 1,511 images, which will be used as an independent evaluation set as described under Design. The segmentation masks will be used as ground truth for a quantitative XAI faithfulness check, as described under Evaluation. In addition, the Diverse Dermatology Images (DDI) dataset will be incorporated as a secondary data source. DDI comprises 656 images, each labelled with a skin-tone group (Fitzpatrick I-II, III-IV, or V-VI, fairly evenly split at 208/241/207 images), a binary malignant/benign flag (171 malignant, 485 benign), and one of 78 specific dermatological diagnoses. Because DDI's 78 diagnoses do not map cleanly onto HAM10000's seven diagnostic classes — a substantial share (for example verruca-vulgaris, epidermal-cyst, acrochordon, neurofibroma, lipoma, molluscum-contagiosum) have no reasonable seven-class counterpart — DDI will be used for a secondary binary malignant/benign classification task rather than forced into the seven-class taxonomy. This is intended to reduce demographic bias in that binary task, directly addressing the limitation identified in the Social Issues section of this proposal, while leaving the primary seven-class task on HAM10000 unaffected. Major research questions that need answering include the best CNN architecture for multi-class image classification, whether accuracy and interpretability are correlated across architectures, and whether the binary malignant/benign task shows more consistent accuracy across skin tones once DDI is included than HAM10000 alone would achieve.
Design:
The proposed approach will include CNN models such as ResNet-50, EfficientNetB4, and VGG-16 because they vary by the degree of depth, size of parameters, and feature extraction capabilities. The dataset contains a large class imbalance problem, with almost 67% of images falling into one class. The preprocessing stage will consist of augmentations (rotations, flipping, zoom, brightness changes) and use of class weighting while training models to balance the problem of imbalanced classes. Because HAM10000's 10,015 images correspond to only 7,470 unique lesions (many lesions are photographed more than once), the train/validation split for the primary task will be performed at the lesion level rather than the image level, to prevent the same lesion appearing in both sets and inflating reported performance. The primary seven-class task will additionally be evaluated on the official ISIC2018 Task 3 held-out test set (1,511 images, disjoint from the 10,015 training lesions) as an independent generalisation check beyond the internal split. As HAM10000 and DDI do not share an identical diagnostic taxonomy, the two datasets will support two distinct classification tasks rather than one forced merge: the primary seven-class task remains HAM10000-only, while a secondary binary malignant/benign task combines HAM10000 (relabelled to malignant/benign from its existing seven-class diagnosis) with the full DDI dataset (which already carries a malignant/benign label). The binary task's combined corpus introduces its own class and source imbalance, since DDI (656 images) is far smaller than HAM10000 (10,015 images); this will be addressed with the same augmentation and class-weighting strategy used for the primary task, extended to account for skin-tone representation. To visualize features extracted by CNNs, two types of XAI techniques will be selected (Grad-CAM and SHAP), applied to both the seven-class and binary models. Revised 17 August 2026: the binary task is now investigated via three comparison approaches rather than one combined-corpus design alone — (1) the joint/mixed corpus described above, (2) a HAM10000-only baseline evaluated zero-shot on DDI with no DDI training at all, used specifically as a generalisation and demographic-bias stress test, and (3) that same HAM10000-only baseline fine-tuned on DDI afterwards at a low learning rate, evaluated against both DDI's held-out split and a HAM10000 retention check. This sequencing (solid single-source baseline first, then measure zero-shot transfer, then decide how to adapt) surfaces information the joint-mixed design cannot produce on its own, since a jointly-trained model has no HAM10000-only counterpart to compare it against.
Development:
Three models described above will be developed using the Python programming language, TensorFlow, and keras. Models will be trained using transfer learning from ImageNet pre-trained models and unfreezing layer by layer for better adaptation to image classification tasks: each architecture is fine-tuned once for the primary seven-class task on a lesion-level split of HAM10000, and once for the secondary binary malignant/benign task on the combined HAM10000+DDI corpus. Both SHAP and Grad-CAM will be applied to each trained model to provide explainability to models' decisions. Experiments will be conducted on Kaggle GPU infrastructure.
Evaluation: 
Evaluation criteria for each model will consist of a multi-metric approach that includes accuracy, precision, recall, per-class F1 score, AUC-ROC, and Cohen’s Kappa, where the latter was chosen to consider class imbalance in reporting performance metrics. For the primary seven-class task, these metrics will be reported both on an internal lesion-level HAM10000 split and on the independent ISIC2018 Task 3 held-out test set. Confusion matrices will be generated to observe inter-class classification errors for all seven classes. For the secondary binary malignant/benign task, performance will additionally be reported stratified by skin-tone group (Fitzpatrick I-II, III-IV, V-VI) using DDI's labels, to assess whether classification accuracy is consistent across skin tones rather than concentrated in the lighter-skinned majority represented in HAM10000. Faithfulness of XAI results will be assessed quantitatively for HAM10000-derived predictions by comparing each thresholded Grad-CAM/SHAP attention map against the ground-truth lesion segmentation mask bundled with HAM10000, using Intersection-over-Union (IoU) and Dice overlap scores, in addition to visual inspection of whether attention zones match discriminative visual features. This quantitative check is available for HAM10000-derived predictions only, since DDI carries no equivalent segmentation masks; DDI's contribution to the binary task's faithfulness assessment remains a visual/qualitative check only. Trade-off analysis between architecture performance and interpretability will be conducted for each model to select the best-performing one. For the binary task's revised three-approach design (see Design), the zero-shot and fine-tuned checkpoints will be evaluated on DDI using the same metric suite and skin-tone stratification as the joint-mixed approach, so all three are directly comparable; a resnet50 pilot (17 August 2026), extended to all three architectures (18 August 2026), found each HAM10000-only baseline's malignant recall collapses on DDI zero-shot (resnet50 0.799 to 0.158, efficientnetb4 0.871 to 0.480, vgg16 0.799 to 0.123), with efficientnetb4's zero-shot skin-tone breakdown showing a clean monotonic decline from lightest to darkest skin. Fine-tuning on DDI is not uniformly beneficial across architectures: it improved DDI malignant recall for resnet50 (to 0.269) and vgg16 (to 0.154), but reduced efficientnetb4's DDI recall (to 0.269, down from its own zero-shot 0.480) — subsequently explained as a calibration-threshold correction toward DDI's true class balance running in opposite directions per architecture, not a genuine discrimination improvement or a fine-tuning-specific weakness in efficientnetb4. Critically, when the original joint-mixed model was evaluated on the identical DDI held-out validation split (18 August 2026), it outperformed both the zero-shot and fine-tuned checkpoints on Cohen's Kappa and AUC-ROC by a wide margin for all three architectures, with a substantially more balanced malignant precision/recall than either alternative. The practical conclusion is therefore that the original joint-mixed training approach remains the project's best-performing binary-task model; the zero-shot and sequential fine-tuning experiments are retained as diagnostic tools that explain the generalisation gap and its calibration mechanics, not as alternatives that outperform joint training, consistent with the Social Issues section's framing that DDI's inclusion measurably reduces but does not eliminate demographic bias.

Social Issues:
The main social issue that arises in connection with the research is the demographics within the HAM10000 database. All the images have been sourced primarily from patients having fairer skin tones from hospitals in Europe and Australia. Since CNN models learn patterns by analysing the training set, a model trained on this dataset might not perform equally well when presented with images of patients having darker skin tones, creating a problem of biased classification results in different population segments. While this issue is specific to the field in question, it is a universal problem with any AI models and their ability to generalise based on training datasets. To mitigate this issue, the project will incorporate the Diverse Dermatology Images (DDI) dataset alongside HAM10000 in training. DDI includes a substantially more diverse range of Fitzpatrick skin types, including darker skin tones under-represented in HAM10000. This is not expected to fully resolve the underlying demographic imbalance, since DDI is considerably smaller than HAM10000 and the combined corpus will still be numerically dominated by lighter-skin-tone images; the residual imbalance and its effect on model performance will be reported explicitly rather than presented as solved.
Ethical issues:
Although there will be no direct involvement with patients, the HAM10000 data set comprises of pictures of actual people. The data set will be treated ethically, solely for the intended research application, and no attempts to unmask any person's identity from anonymized data will be undertaken. From an AI ethics perspective, one of the most significant issues is that of model misclassification. In the specific context of malignancy vs. benign image classifications, such a misclassification error will manifest itself in terms of false negative errors. The current research project will not involve developing any clinical application but will instead function as a controlled classification experiment, and all model outputs will be presented strictly as experimental findings.
